# 화도(슬롯) 관리 재디자인 — Figma Make 붙여넣기용 프롬프트

**목적**: 货道管理(화도 관리) 화면만 남은 기존 중국어·라이트·청록 UI를, 나머지 앱과 동일한 **한국어 럭셔리 다크 테마**로 재디자인. 기능·데이터 구조는 100% 유지.
**실행 시점**: Figma Make 일일 AI 크레딧 복구 후 (다음 날 리셋)
**대상 파일**: Kiosk-App-UI-Redesign (버전 6 기준)

## 붙여넣기용 프롬프트 (한국어)

> 货道管理(화도 관리) 관리자 화면을 나머지 앱과 동일한 **한국어 + 럭셔리 K-뷰티 다크 테마**로 재디자인해줘. 현재 이 화면만 기존 중국어·라이트·청록 셀 UI가 남아 다른 화면(기기정보/고객서비스/결제설정 등 다크)과 불일치해. **기능·레이아웃 구조·데이터(층/열/슬롯 번호)는 그대로 유지**하고 시각 디자인만 통일해줘.
>
> **해상도**: 1080×1920 세로형 고정, 기존과 동일한 auto-scale.
>
> **유지할 기능 (한국어로 라벨 변경)**
> - 상단 타이틀: 货道管理 → **"화도 관리"**
> - 상단 우측 액션 버튼 3개: 恢复配置 → **"설정 초기화"**, 保存配置 → **"설정 저장"**, 返回 → **"뒤로"**
> - 설정 행: 货柜地址 → **"장비 주소"**(드롭다운), 层 → **"층"**, 列 → **"열"**, XY刻度 → **"XY 좌표"** 버튼
> - 옵션: 循环 → **"순환"** 체크박스, 显示编号 → **"번호 표시"** 체크박스
> - 도구 버튼: 设置 → **"설정"**, 编辑格子 → **"격자 편집"**, 全体测试 → **"전체 테스트"**
> - 격자: **6층 × 10열** 그리드 (NO.1층~NO.6층 행 라벨, 각 행에 셀 1~10). 셀 개수·번호 체계 유지.
> - 하단 상태바: WiFi · 设备信息 → **"기기정보"** · 售后信息 → **"고객서비스"** · 브랜드 로고
>
> **디자인 토큰 (다른 화면과 통일)**
> - 배경: 딥 플럼 다크 (#17131A 계열), 서피스 카드 (#211B26)
> - 텍스트: 밝은 오프화이트, 보조 텍스트는 뮤트 그레이(마우브 편향)
> - 액센트/주요 CTA(설정 저장 등): 로즈골드 (#B76E79~#D69AA6)
> - 격자 셀: 청록(#7BD3D0) 대신 **다크 서피스 + 로즈골드 테두리/선택 강조**, 상태별 색(정상=초록/빈칸=뮤트/오류=레드)
> - 폰트: 나머지 화면과 동일 (한국어 sans)
>
> **키오스크 터치 UX**
> - 모든 버튼·셀 탭 타겟 최소 56px 이상, 넉넉한 패딩
> - 셀 선택/편집 시 active:scale 피드백
> - 격자가 길면 세로 스크롤, 상단 액션바는 sticky
>
> **주의**: 슬롯 번호·층/열 구조는 실제 자판기(鑫之源) 화도 프로토콜과 매핑되므로 **번호 체계를 임의로 바꾸지 말 것.** 라벨 언어와 시각 스타일만 변경.
