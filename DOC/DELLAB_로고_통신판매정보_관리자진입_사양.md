# DEL LAB 로고 / 통신판매사업자 정보 / 관리자 진입 — 요구사항 & 사양

**작성일**: 2026-07-14
**대상**: 키오스크 구동 앱 (Kiosk-App-UI-Redesign) — 크레딧 복구 후 Figma Make 또는 신규 프로젝트 반영
**요청 요약**: 자판기 공급자 로고(森之源/鑫之源) → **DEL LAB**으로 교체, 로고 탭 시 법적 고지 페이지, 로고 5회 연속 탭 시 비밀번호 게이트 후 자판기 설정 진입.

---

## 1. 로고 교체 — DEL LAB

- 기존 공급자 로고(森之源/鑫之源 XINZHIYUAN)가 노출되는 **모든 위치**를 DEL LAB 로고로 교체.
  - 하단 시스템 상태바 우측 브랜드 로고
  - 관리자/설정 화면 하단 로고
  - (해당 시) 대기화면·기타 공급자 표기
- 로고 에셋: **DEL LAB** (라운드 스퀘어 아이콘 안 "del" + 워드마크 "DEL LAB", 그레이 #4F4F4F 계열). → Make 작업 시 실제 로고 파일 업로드 필요.
- 다크 테마 대비 위해 로고는 화이트/라이트 버전도 준비 권장.

## 2. 로고 탭 → 통신판매사업자 정보 페이지 (신규 · 고객 대면)

한국 전자상거래법상 필수 고지. 로고 탭 시 전체화면 페이지(또는 대형 모달) 오픈.

**노출 항목 (값은 확정 필요 — 아래 `«»`는 채워넣을 자리)**
- 상호(사업자명): «DEL LAB / 법인명»
- 대표자: «대표자명»
- 사업자등록번호: «000-00-00000»
- 통신판매업 신고번호: «제 0000-지역-0000 호»
- 사업장 주소: «주소»
- 고객센터 전화: «1946-4775 등» (기존 AS 모달과 일치 여부 확인)
- 이메일: «support@…»
- 운영시간 / 개인정보 관리책임자(선택)
- (권장) 결제대행(PG)·호스팅 사업자 표기

**UX**
- 닫기(X) 버튼으로 이전 화면 복귀
- 다크 테마·한국어, 본문 가독성 위해 큰 폰트(키오스크 시야거리)
- QR: 상세 약관/전자문서 링크(선택)

## 3. 로고 5회 연속 탭 → 관리자 진입 (비밀번호 게이트)

**중요 — 단일 탭(2번)과 5회 탭(3번)의 충돌 해소**
같은 로고에서 "1회=법적 고지" / "5회=관리자"가 겹치므로 탭 카운터로 분기:

> **✅ 확정 (A안)**: 로고 탭 시 카운터 시작.
> - **2초 이내 5회 연속 탭** → 통신판매 정보 네비게이션 취소하고 **관리자 PIN 입력** 화면으로.
> - 그 외(1회 탭 후 짧은 디바운스 ~400ms 경과) → **통신판매사업자 정보 페이지**.
> - 구현 노트: 탭마다 카운트+타임스탬프, 마지막 탭 후 400ms 타이머로 단일탭 확정. 2초 창 내 5회 도달 시 즉시 관리자 분기 + 타이머 취소.

~~대안(B안: 정보 페이지 내 5회 탭)~~ — 미채택.

**관리자 비밀번호 게이트**
- 숫자 PIN 패드(터치), 마스킹 표시, 오입력 시 흔들림 피드백
- 인증 성공 → **관리자 모드(설비 메뉴 허브 设备配置)** 진입, **기본 랜딩 = 일반설정(환경설정 常用配置)**
- ⚠️ **결제설정으로 직행 금지** — 결제설정(현금설정 现金配置)은 설비 메뉴 안의 한 항목일 뿐. (현재 앱은 결제설정만 존재해 여기로 빠지는 오류 → 허브+일반설정 생성으로 보정)
- 설비 메뉴 항목: **일반설정(환경설정)** · 화도(슬롯)관리 · 현금설정(=기존 결제설정) · 현금통계
- 실패 N회 시 일시 잠금(선택), 기본 비번은 일반설정의 비밀번호 변경(修改密码)과 연계
- 기존 "기기정보 모달 제목 5회 탭" 히든 진입은 **이 방식으로 대체/통일**

## 4. Figma Make 붙여넣기용 프롬프트 (확정 · 1단계)

> 기존 한국어 럭셔리 다크 테마를 유지하면서 아래를 반영해줘.
>
> **(1) 로고 교체**: 자판기 공급자 로고(기존 森之源/鑫之源/XINZHIYUAN)가 노출되는 모든 위치(하단 시스템 상태바 우측, 관리자·설정 화면 하단 등)를 **DEL LAB** 로고로 교체해줘. 로고 에셋은 내가 업로드할 DEL LAB 이미지를 사용하고, 다크 배경에서 잘 보이게 처리해줘.
>
> **(2) 로고 1회 탭 → 통신판매사업자 정보 페이지(신규)**: 전체화면 페이지(또는 대형 모달)로 아래 항목을 "라벨: 값" 형태로 크게(키오스크 가독성) 표시. 값은 플레이스홀더로 비워두고 나중에 채울 수 있게. 우측 상단 닫기(X)로 복귀. 다크·한국어.
> - 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 사업장 주소, 고객센터 전화, 이메일, 운영시간
>
> **(3) 로고 5회 연속 탭 → 관리자 PIN 진입 (A안)**: 같은 로고에서 탭 카운터로 분기.
> - 탭마다 카운트+시각 기록. **2초 이내 5회 연속 탭** → 통신판매 정보 이동 취소, **관리자 PIN 입력 화면**(숫자 패드·마스킹·오입력 흔들림).
> - 그 외(1회 탭 후 ~400ms 추가 탭 없음) → 통신판매 정보 페이지.
> - PIN 인증 성공 → 자판기 설정(설비 메뉴) 이동.
>
> **(4)** 기존 "기기정보 제목 5회 탭" 관리자 진입은 위 로고 5회 탭 + PIN 방식으로 통일(대체)해줘.
>
> 터치 UX: 모든 탭 타겟 최소 56px, active:scale 피드백.

## 7. 관리자 모드 · 일반설정(常用配置) 하부 구성 (실측 확정)

**관리자 모드 = 설비 메뉴 허브**, 기본 랜딩 = 일반설정.
```
관리자 모드 (설비 메뉴)
├─ 일반설정(환경설정) 常用配置   ← 기본 랜딩
├─ 화도(슬롯)관리 货道管理
├─ 현금설정 现金配置 (= 기존 결제설정)
└─ 현금통계 现金统计
```

**일반설정 6개 그룹 + 하단(뒤로/제출)**
1. **자주 쓰는 작업(常用操作)** — 버튼 → 하위 화면/다이얼로그
   - 비밀번호 변경 → 비번 변경 화면 · WiFi 설정 → WiFi 화면 · 시스템 설정 → 시스템 화면
   - 시스템 재시작 / 메인보드 재시작 / 구버전 제거 → 각 확인 다이얼로그
2. **화면 설정(界面配置)** 토글 7 — 내비게이션바(OFF) · 종류목록(ON) · 장바구니(ON) · 구매 애니메이션(ON) · 애니메이션/영상(ON) · 화면 언어선택(ON) · 첫화면 표시(ON)
3. **시간 설정(时间配置)** — 첫화면 복귀 90초 · 장바구니 수량 5
4. **언어 선택(语言选择)** — 언어 모달 열기(고객 모달 재사용)
5. **테마 설정(主题配置)** 라디오 — 종합기(파랑)● · 종합기(노랑) · 블라인드박스기
6. **기타(常用配置)** 토글 3 — 전자 가격표(OFF) · 조명(OFF) · 단선 재시작(OFF)

### 붙여넣기용 프롬프트 (일반설정 화면 · 2단계-보정 이후)
> 관리자 모드의 "일반설정(환경설정)" 화면을 아래 6개 그룹 카드로 만들어줘(다크·한국어, 키오스크 큰 터치 타겟). PIN 성공 후 여기가 기본 랜딩이야.
> 1) 자주 쓰는 작업(버튼→하위화면): 비밀번호 변경, WiFi 설정, 시스템 설정, 시스템 재시작, 메인보드 재시작, 구버전 제거. 재시작·제거는 확인 다이얼로그.
> 2) 화면 설정(토글): 내비게이션바(기본 OFF), 종류목록(ON), 장바구니(ON), 구매 애니메이션(ON), 애니메이션/영상(ON), 화면 언어선택(ON), 첫화면 표시(ON)
> 3) 시간 설정: 첫화면 복귀(초) 기본 90, 장바구니 수량 기본 5 (숫자 입력)
> 4) 언어 선택: 기존 언어 모달 열기
> 5) 테마 설정(라디오): 종합기(파랑) 기본 선택, 종합기(노랑), 블라인드박스기
> 6) 기타(토글): 전자 가격표(OFF), 조명(OFF), 단선 재시작(OFF)
> 하단 고정 버튼: 뒤로, 제출(변경 일괄 저장). 설비 메뉴에서 화도관리·현금설정·현금통계로 이동 가능.
